## 两个筛选步骤各自解决什么问题

新增编号只说明辅助地图上的候选未匹配到主图已有实例。上一版这些编号在验证中贡献了 2 个命中和 245 个误检。采用训练组选定的规则，撤销这些候选的语义与实例标签，在 PLY 中写为未标注。评估时，落到未标注点上的真值仍参与评分，几何保留的点也仍参与距离统计。只做这一步，2 个命中和 245 个误检均退出，在原点集上得到 51.14% PQ。

几何筛选优先保护已经配到主图实例的补点。其余补点需要同时满足两个条件。一是两条估计轨迹对同一帧实测深度的投影没有持续给出自由空间反证。二是点离主图足够近，或者能沿同类局部平面向外延伸。主配置的近邻距离为 5.5 cm，同类平面外推上限为 18 cm，局部平面由主图最近的 18 个点估计。宽松对照使用 7 cm 和 30 cm，并放宽法向残差。代码给出完整判据。[平面与实例筛选](../../../tools/surface_continuation.py) · [实测深度判据](../../../tools/filter_free_space_points.py)

联合方案保留原有 19,324,053 个补点中的 **6,305,312 个**。保留点中有 20.77% 落在真值表面 5 cm 内，剔除点中这一比例为 11.19%。用同一参考坐标系下 5 cm 体素格重新统计，每个占用格只计一次，地图侧精确率仍从 51.87% 提高到 54.80%，真值侧覆盖从 91.38% 降至 89.48%。[等密度几何明细](equal-density-geometry.csv)

## 从已完成的 ReVeMap 重建运行

先按双表面流程生成 `$FUSED`，并在主图联合位姿图的 `apply` 命令上加 `--save-trajectory` 导出与主图相同的强轨迹。辅助轨迹使用 ORB 半位姿重融导出的 `trajectory.json`。这两个文件均为估计轨迹，原始 RGB-D 使用同次 ScanNet 录制的 `.sens`。[双表面流程](../complementary-surfaces.md) · [主图联合位姿图](../joint-geometry.md) · [辅助轨迹](../orb-half-surface.md)

```bash
python tools/guard_added_instances.py \
  --input "$FUSED" --sensor "$SCENE_SENS" \
  --primary-trajectory "$JOINT_OUTPUT/trajectory.json" \
  --secondary-trajectory "$ORB_OUTPUT/trajectory.json" \
  --surface-policy tight --output "$GUARDED_OUTPUT"
```

`--surface-policy relaxed` 复现宽松对照。仅传入 `--input` 和 `--output` 可复现只撤销新编号标签的一组。每个输出目录保存 `map_labeled.ply`、`panoptic.npz`、类别表及输入输出哈希。评分时使用确定原始地图坐标系的原生估计轨迹。[完整真值域评分命令](../full-domain-scoring.md)

从冻结的补点与深度筛选结果出发，发布函数逐点复现了两档阈值下全部 142 场的点选择、语义和实例编号。在 `scene0063_00` 上另用原始传感器、两条估计轨迹及原双表面 PLY 运行完整命令，输出 426,398 点，用独立评分器得到 PQ 56.5059%、9 个命中和 7 个误检，逐项与封存记录一致。[全量逐点回放](release-replay142.json) · [示例导出哈希](scene0063-result.json) · [示例评分](scene0063-score.json)

## 验证范围和不确定性

复用上轮封存的 142 对主图和辅助地图，三个主组件的输出相同。9 条房间家族互斥的官方训练扫描用于选择策略，在 22 个联合参数组合中，先要求误检和双向均距下降、精确率上升、PQ 较原补点下降不超过 0.35 个百分点，再取地图精确率最高的一项。训练组平均 PQ 从 62.14% 变为 62.09%，误检从 86 降至 78。[训练比较](development.csv) · [验证前冻结记录](frozen.json)

确认集为官方 312 条验证扫描中既定的 142 条，共 134 个房间家族。保持相同首对相机对齐、完整标注真值域、5 cm 最近邻投影和严格大于 0.5 的实例 IoU 匹配。与上一版逐场比较，PQ 有 58 升、11 平、73 降，新增 5 个真值匹配、失去 3 个。按房间家族重采样 10,000 次，平均 PQ 变化为 −0.15 个百分点，95% 区间为 −0.57 至 +0.26。联合方案的绝对 PQ 均值区间为 **46.77% 至 54.00%**。该验证子集曾用于多轮实验，50.40% 是这批扫描上的均值。[各组汇总及区间](summary.json) · [逐场独立核对](independent-replay.json)
