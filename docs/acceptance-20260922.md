本轮按“工程可靠性优先，算法变化独立验证”的范围整理。保留原版默认输出；新增策略均需要显式启用。这里的运行时间是单次观测，查询 oracle 是软件契约检查，均不等同于算法准确率提升。

基线为 `0d462120c8da6c7997083db668a7de0bdf8e3bac`。对 scene0030_00、scene0050_00、scene0011_00 使用相同几何、点序和已有 SAM3 masks：

## 工程与查询修复

- 每次重新处理创建新 attempt。仅在原始帧、选项、源码、外部模型代码/权重、解释器包版本、真实 worker runtime 副本和产物摘要一致时复用完整 mapping/SAM3；每次阶段封存及最终完成都会重新核验。部分输出、旧版无seal和失效缓存重新计算。
- 重绑定新尝试中的地图、轨迹、裁图和视角计划路径及摘要，保留原尝试不变。VLM、融合、命名、refinement 重新运行；复用的 `raw_fps` 为 null。
- 取消、父进程强杀、阶段主进程先退出，都清理本次拥有的进程组；独立看门狗清理未安装 hook 的后代。正常退出也验证退出码为 0，避免退出清理把成功阶段误报为失败。
- GUI 提交完成前校验 GUI_RESULT、ARTIFACTS、输入与完整轨迹，以及 session/attempt/pipeline 归属。旧地图不能冒充失败的新尝试；旧进程组未退出时拒绝重试。
- 场景图只分组一次，用空间候选筛选减少稀疏图的两两计算。密集图超过显式候选上限时报错，不返回假装完整的部分图。拒绝重复实例、自环、悬空关系和垂直关系环。
- 查询保留等距结果、缺失目标、未知名称及缺重力方向的拒答；类别与多帧名称冲突附带来源。评价要求前后共享同一类别集合，结束时复查文件、状态与最终清单，防止分母或来源漂移。

30 条独立人工定义的几何查询预期全部通过，包括 11 条预期 unknown；另有 5000 实例/关系链、大图候选等价检查，以及三份真实旧地图的构图与查询检查。**这不是 30/30 的模型识别结果，也不是实际接触或物理支撑验证。**

## 真实流程验收

`source-v1` 在 RTX 4060 Laptop 8 GiB 上从 scene0030_00 前 120 帧原始 RGB-D 重新运行 DROID 跟踪、图优化、回填、TSDF、25 帧 SAM3、Qwen3-VL-2B NF4 命名、融合、命名回填和 GUI 结果封存；mapping/SAM3 均未复用。完整轨迹与积分帧数均为 120，输出 40,669 点、6 个实例，3 个实例有合格多帧名称。流水线计时 99.883 秒；包含输入散列与封存的外层墙钟 102.071 秒。

这只覆盖该序列开头的一个窗口：完整 GT 几何覆盖约 9.68%，支持范围内 unknown-as-error 准确率约 79.35%，完整 GT 上未知/未覆盖均计错时约 4.635%。类别相关实例召回为 0/53，类别无关为 1/90（IoU ≥ 0.5）。唯一类别无关匹配的 GT 类别为 armchair，预测 chair；预注册的精确共享名称协议没有事后扩展别名。不能据此声称完整场景准确率为 79%、超过旧 A/B，或证明更广泛的泛化提升。

最终 `source-v2` 的真实强杀/恢复、测试与安装结果见下方记录；v1 结果保留为独立运行，不覆盖或冒充最终版本。

`source-v2` 在同一原始 120 帧上重新完成 mapping/SAM3，待 VLM 写出第一个真实响应后对主进程发 SIGKILL。所有记录的所属进程均退出，未产生假完成结果。随后新目录恢复：mapping/SAM3 两个阶段均通过校验复用，轨迹、所有 masks 与原尝试相同；原尝试所有文件未变。重新运行 VLM、融合、回填及可选 refinement 后 GUI 最终封存成功，外层墙钟为 43.441 秒。该时间是复用运行，不能作为全流程 FPS 或与上述 102 秒直接计算性能提升。

refinement 本次准备了 3 个对象、11 张裁图，其中 2 个对象满足观察条件；实际 grounding 请求为 0，改变点数为 0。因此只验收了整条分支的正常完成与无候选行为，**没有验收真实正样本的补全收益**。有候选时的判定与保护约束另由 CPU 反例测试覆盖。

最终运行源码在 macOS / Python 3.12 上为 304 passed、1 skipped（本地未安装 Open3D）；Linux / Python 3.11 + Open3D 0.19 为 305 passed、无 skip。CI 对 Python 3.11/3.12 执行完整 CPU 回归、构建和 checkout 外 wheel 安装/查询。机器可读摘要见 [validation-summary-20260922.json](validation-summary-20260922.json)。

## 尚未验收的范围

没有连接可用于本轮验收的 Orbbec 实机，因此相机物理拔插、无线链路恢复与长时间现场扫描尚未验收。真实子进程强杀、合成帧和回放测试只覆盖软件恢复行为。已提供的自适应选帧、track 置信度和 abstain 策略没有达到提升默认配置的接受条件；它们保留为实验选项。阶段复用不包含 VLM 或 refinement 内部的部分计算。

本轮未新增独立 heldout 的精度对照，也未重测所有 VLM 后端。可合入判断针对上述已验证的默认行为、工程接口及明确隔离的实验选项。
