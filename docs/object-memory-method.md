# ssh33 对象记忆对照实验

这次验证 ConceptGraphs 的对象记忆思路在 ReVeMap 命名阶段的价值，不是重跑官方 ConceptGraphs 整条建图流程。原始几何、SAM3 mask、相机轨迹固定；真实执行 CPU 融合、Qwen3-VL 命名和按需 OpenCLIP 推理。实验代码不接管正式 pipeline。

## 固定设置

- 融合代码基线：`931dfbac4d27a679a74cdd4ee67e6a107a09537a`。
- 预测实现：`b434b3e`，后续 `ea258bc` 只增加评估程序。
- 机器：`aidenwu@100.72.138.33`，RTX 4060 Laptop 8 GB。
- Qwen3-VL-2B-Instruct，NF4，逐张推理，固定提示词与贪心生成；所有实验组采用 2 个 CPU 线程。
- CLIP：ViT-H-14 / laion2b_s32b_b79k，FP32、batch 1，只运行图像编码器，使用与 VLM 相同的裁剪图。
- 复用既有 Qwen 与 ConceptGraphs 环境及验证回执；没有安装包、重建环境或改变服务。
- 五个场景，每个 25 个视角，总计 570 张候选裁剪图。前三个使用此前固定的中间窗口；新加入 scene0000_00、scene0062_00 的缓存中间 25 个视角。两组额外场景的完整重建结果此前存在，但本次对象选择规则没有用其 GT 调参。

早期输入审计发现旧 crop pool 与固定的 SAM3 mask 来自不同推理。该准备尝试在模型运行前停止，空目录保留为 `failed-input-preparation-v1`。前三个场景的裁剪图改由固定 mask 和有哈希记录的配准 RGB 生成，沿用面积、尺寸、前 8 个与 15% padding 规则；两个额外场景直接使用同一原始 SAM3 推理输出的裁剪图。所有实验组都读取同一份裁剪图。

## 三组实际行为

| 组别 | 处理方式 | 调度 |
|---|---|---|
| A | 识别所有裁剪图，按原规则回填名称 | VLM 与 CPU 融合重叠 |
| B | 用融合后的预测物体分组；选最多 3 个不同视角；无法达成至少两帧支持的严格多数时，识别该物体的剩余有效裁剪图 | 先融合，再选择与命名 |
| C | B 加上有歧义的裁剪—物体关联的 CLIP 复核；只会撤回关联，不会扩大几何支持或合并物体 | 先融合，再 CLIP，再 VLM；GPU 模型分进程释放 |

代表视角先看 mask 面积与几何归属比例，再在质量足够的视角中选择观察方向不同的图像。没有用 VLM 已有答案或 GT 选图。每个名称只有真实推理过的不同原始帧能投票，复用一次结果不会增加支持帧数。

C 的几何触发条件为归属比例小于 0.8，或另一物体至少占 30 个点且比例不小于 0.15。只有满足原始回填条件（至少 30 点、归属比例至少 0.65）的图像才可进入命名。使用至多两个可靠、不同帧的原型；自身 cosine 小于 0.70，或与竞争原型差值小于 0.05，则撤回关联。没有独立原型时保持几何决定。这些阈值在查看本次 GT 结果前固定。

## 计时与质量边界

每场景按 A→B→C、C→B→A 各测一次，每组新建模型进程，不复用过去的 VLM 结果或 CLIP 特征。计时包含子进程、模型加载、融合、对象分组、按需 CLIP、VLM、导出与命名回填；B/C 等待融合所损失的并行也包含在内。输入准备、哈希封存和 GT 评估在计时外。

第一轮第一个 A 与第一个 CLIP 进程有显著首次加载开销；报告分别列两轮，以第二轮的文件缓存已热结果作为保守主要比较。第二轮也重新加载模型，GPU 权重没有跨组驻留。两次重复不足以给出稳定的统计置信区间。

这不是从原始 RGB-D 开始的端到端耗时。SLAM、SAM3 和后续完整 GUI/查询没有重新执行，不能把这里的百分比直接用于整条 pipeline。显存数据是推理进程的 PyTorch reserved/allocated，不是包含桌面的整机峰值；RSS 也是单进程峰值。

所有预测先封存，再访问 GT。分别检查三类结果：

1. 点云坐标、semantic、instance、confidence 数组是否完全一致；前三个场景另与历史固定基线比对。
2. 所有实例的最终名称、未知状态、跨重复结果是否一致。
3. 固定的 GT 支持命名诊断：5 cm 以内、至少 30 个有标注的支持点、至少 50% 的物体点有支持、至少 80% 来自同一 GT 物体、且具有至少两帧有效裁剪证据。仅评价共享类别中的前景物体。使用已有 scene_graph 别名字典，未知和更细的未识别词汇分别报告，不事后添加同义词。

第 3 项是小样本的严格名称核对；不是完整的开放词汇语义正确性评估，也不是 ScanNet 官方 AP/mIoU。不能由名字一致推断没有遗漏未知物体。
