2026-09-29 按用户要求，仅保留对象记忆 B 的优化实现。A 是原版识别所有裁剪图的验证对照。CLIP 复核 C、上下文复核 D/E 的代码、入口与活动证据已移除；原始实验与 Git 历史保存在清理回执列出的恢复副本中。

## B 的行为

1. 使用现有融合后的预测实例对裁剪图分组，保持至少 30 个支持点、归属比例至少 0.65 的条件。
2. 每个对象选择最多 3 个不同原始帧，依据 mask 面积、几何归属比例和视角差异选择。
3. 只有真实推理的不同原始帧可以投票；若没有至少两帧支持且领先其他名称的共识，继续识别该对象其余有效裁剪图。
4. 少于两个有效原始帧的对象不发起无效命名请求。名称只回填元数据，不改变 XYZ、点云类别、实例归属或置信度。

对象关联、代表视角选择、投票和缓存身份函数保留原实现。尚未实现跨运行持久缓存，也尚未合入正式 pipeline。
