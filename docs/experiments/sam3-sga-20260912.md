# SAM3 semantic fusion and measured SGAligner comparison

Experimental modules over frozen RGB-D trajectories and map vertices. Production entrypoints/defaults are unchanged. Base: developnew 0c94449.

- `sam3_mapping`, `sam3_fusion`, `sam3_export` and indoor taxonomy preserve the preceding SAM3 trial.
- `sam3_refine` resolves compatible desk/table and curtain-subtype conflicts using measured SGF anchors, or retains explicit unresolved coarse categories.
- `sam3_sga` creates objects from observed mask interiors, executes the existing SGAligner pct/gat/rel checkpoint, and compares cross-stream top-three retrieval against measured geometric association. Both arms use the same geometry gates and object consensus. No transform is applied to the trajectory.

Three ScanNet scenes, one Orbbec sequence and a six-frame 3RScan input sample were evaluated on ssh44. They are sparse semantic-frame runs over frozen full maps, not fresh full-frame reconstruction. No OneFormer or inference-time GT is used. Existing SGF priors contain earlier SGA results; this comparison measures the added SGA association stage.

Validation: 22 focused tests passed; real SAM3 and SGAligner inference completed on all five samples; 15 labeled exports preserve original vertex properties and array/object inventory consistency. These checks do not imply universal quality acceptance.

Results: ScanNet0030 correct semantic coverage improved from 55.07% (previous SAM3) to 65.62% (geometric object consensus). Orbbec semantic coverage improved from 28.78% to 35.75%, without semantic GT. Instance purity on ScanNet0030 fell from 95.97% to 93.21%, although object recall increased. Added SGA did not consistently beat geometric association. Retain the conservative family-only stage and both object-association arms for review; do not promote this experiment to production on coverage alone.
